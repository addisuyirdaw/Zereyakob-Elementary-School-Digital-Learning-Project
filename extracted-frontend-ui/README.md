# Standalone React UI Template

This is a standalone, isolated frontend UI project extracted from HomeLink-Ethiopia.

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

## Configuration
To connect to a backend API, create a `.env` file in the root folder and add:
```env
VITE_API_BASE_URL=http://localhost:8000
```
